PBI Test Utility

Generate synthetic bond, loan, and interest capture events against any TrOWE environment — without touching production data.

What this is

Three engines. One interface.

Bonds
Bond Issuance
EVENT_NEW_ISSUANCE_DATA

Posts new bond issuance events. Configure issuer, size, coupon, tenor, bookrunners, and currency — or pull values from reference CSVs.

Loans
Loan Issuance
EVENT_CREATE_NEW_LOAN_ISSUANCE

Posts loan issuance events with multi-tranche support. Tranches are linked automatically via ALL_LOAN_DEAL.

Interest
Interest Capture
EVENT_INTEREST_CAPTURE

Posts interest capture events for existing loan deals. Targets a running deal by ID and submits capture data.

Setup

Getting started

01

Get the folder

Copy the PBI_Test_Utility folder to your machine — from a shared drive, git clone, or zip. Anywhere works; the app is fully self-contained.

02

Run Setup.bat — once

Double-click Setup.bat. It creates a Python virtual environment and installs all backend and frontend packages. Takes around a minute on first run, skips everything that already exists on subsequent runs.

[1/4] Creating Python virtual environment... OK
[2/4] Installing Python dependencies... OK
[3/4] Installing Node packages... OK
[4/4] Setup complete!
03

Launch the app

Double-click Launch.vbs. Both servers start silently in the background and your browser opens to http://localhost:5173 within a couple of seconds. No terminal window.

04

Configure an environment

Open the Settings tab. Add at least one environment — give it a name, paste the host URL, and enter your credentials. The active environment is shown in the header and persists between sessions.

Reference

The interface

Bond Issuance

Configure and submit one or more EVENT_NEW_ISSUANCE_DATA events. Set issuer name, deal size, currency, coupon rate, tenor, and bookrunners. Values can come from reference CSVs under backend/reference/bonds/, or you can enter them manually.

The live log streams each event's result as it posts — green rows for ACKs, red for NACKs with the full error payload.

Loan Issuance

Posts EVENT_CREATE_NEW_LOAN_ISSUANCE events. Supports multi-tranche deals: the first tranche creates an ALL_LOAN_DEAL master record, and subsequent tranches are linked to it automatically.

Several numeric fields (SPREAD, YIELD, OID) must be sent as strings per the server schema — the engine handles this for you.

Interest Capture

Posts EVENT_INTEREST_CAPTURE events for an existing loan deal. Provide the deal ID and capture parameters. Useful for testing the full lifecycle after a loan issuance run.

Run History

Lists every run you've completed — tool, environment, timestamp, and outcome. Click any entry to prefill the form with the same parameters so you can repeat or tweak a test without re-entering values from scratch.

History is stored locally in backend/history.json.

Environments

Add, edit, or remove named environments. Each environment stores: host URL, username, password, and an SSL verification toggle. The active environment is switched from the dropdown in the header — the change takes effect immediately for the next run.

Credentials are stored in plain text in backend/environments.json — this tool is for test environments only, never production.

Shutdown

Stopping the app

STOP

Double-click Stop-App.vbs

Terminates both the FastAPI backend (port 8000) and the Vite frontend (port 5173). Safe to run at any time — won't affect other processes on those ports unless the app is running.

Good to know

Tips

Dry run

Test payloads without a server

Enable Dry Run on any tab to skip authentication and POST calls entirely. The full generated payload prints as formatted JSON in the log — useful for inspecting field values before a live run.

Environments

Switch targets on the fly

Use the environment dropdown in the header to point at a different host mid-session. The selection persists in environments.json so it's still active next time you launch.

Re-run

Repeat from History

The History tab lets you click any past run to prefill all parameters. The run never fires automatically — you still press Submit, so you can adjust anything before it goes.
